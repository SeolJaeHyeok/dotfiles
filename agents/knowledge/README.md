# Shared Knowledge Archive

이 디렉터리는 `ce:compound` 같은 host 전용 지식 저장 경로를 사용할 수 없을 때 쓰는 공통 fallback 저장소다.

## 파일명 규칙

- 형식: `YYYY-MM-DD-topic-slug.md`
- topic slug는 기능명, 버그명, 영역명을 짧게 정리한다

## 본문 형식

```markdown
## [주제] — [날짜]

**컨텍스트**: [어떤 작업이었는가]

**핵심 결정**: [선택한 접근법과 이유]

**발견**: [예상과 달랐던 점]

**실수**: [잘못 판단한 부분과 원인]

**다음 번엔**: [다시 이 영역을 건드릴 때 알아야 할 것]
```

빈 문서는 만들지 않는다. 공유 가치가 있는 내용만 남긴다.
