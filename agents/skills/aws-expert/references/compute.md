# AWS 컴퓨팅 서비스 레퍼런스

## 서비스 선택 가이드

| 상황 | 추천 서비스 | 이유 |
|------|-----------|------|
| 24시간 돌아가는 웹서버 | EC2 | 상시 구동, 직접 제어 가능 |
| 간헐적 API 호출 | Lambda | 호출 시만 비용, 관리 불필요 |
| Docker 컨테이너 운영 | ECS Fargate | 서버 관리 없이 컨테이너 실행 |
| 대규모 컨테이너 오케스트레이션 | EKS | K8s 경험이 있을 때만 |

## EC2

### 초보자 권장 설정
- 인스턴스 타입: `t3.micro` (프리 티어) 또는 `t3.small` (소규모 프로덕션)
- AMI: Amazon Linux 2023 (최신, 보안 패치 자동)
- 스토리지: gp3 20GB (gp2보다 저렴하고 빠름)
- 보안 그룹: SSH(22)는 내 IP만, HTTP(80)/HTTPS(443)는 0.0.0.0/0

### 자주 하는 실수
- 인스턴스를 중지(Stop)하면 EBS 비용은 계속 발생함 → 실습 후 종료(Terminate) 권장
- 탄력적 IP를 할당하고 인스턴스에 연결 안 하면 비용 발생
- t3 계열 CPU 크레딧 소진 시 성능 저하 → 프로덕션은 unlimited 모드 고려

### 비용 (서울 리전, 2026 기준)
| 타입 | vCPU | 메모리 | 월 비용 (온디맨드) | 프리 티어 |
|------|------|--------|-------------------|---------|
| t3.micro | 2 | 1GB | ~$11 | 12개월 750시간/월 |
| t3.small | 2 | 2GB | ~$22 | X |
| t3.medium | 2 | 4GB | ~$44 | X |

## Lambda

### 초보자 권장 설정
- 런타임: Node.js 20.x 또는 Python 3.12
- 메모리: 256MB (대부분 충분)
- 타임아웃: 30초 (API용), 900초(15분, 배치용)
- 환경 변수로 설정값 관리 (하드코딩 금지)

### 자주 하는 실수
- 콜드 스타트: VPC에 넣으면 초기 호출이 느려짐 → VPC 필요 없으면 넣지 말 것
- 동시성 기본 한도 1000개 → 대규모 트래픽 시 한도 상향 요청 필요
- CloudWatch Logs에 로그가 계속 쌓임 → 보존 기간 설정 필수

### 비용
- 월 100만 요청 + 40만 GB-초 무료
- 이후: 100만 요청당 $0.20 + GB-초당 $0.0000166667
- 대부분의 소규모 프로젝트는 프리 티어 내에서 가능

## ECS (Fargate)

### 초보자 권장 설정
- 시작 유형: Fargate (서버 관리 불필요)
- CPU: 0.25 vCPU / 메모리: 0.5GB (소규모)
- 태스크 수: 1 (시작), 오토스케일링으로 확장

### EC2 vs Fargate
| 기준 | EC2 시작 유형 | Fargate |
|------|------------|---------|
| 서버 관리 | 직접 | AWS가 관리 |
| 비용 (소규모) | 저렴 | 비쌈 |
| 비용 (대규모) | 저렴 | 비쌈 |
| 시작 난이도 | 높음 | 낮음 |
| 추천 대상 | 서버 관리 가능한 팀 | 빠르게 시작하려는 팀 |
