# 초보자 공통 아키텍처 패턴

실제 서비스에서 가장 많이 쓰이는 AWS 구성 패턴을 난이도 순으로 정리한다.

## 패턴 1: 정적 웹사이트 (난이도: 하)

React/Vue/Next.js 빌드 결과물을 호스팅.

```
[사용자] → [CloudFront (CDN)] → [S3 (정적 파일)]
                                    └── OAC로 직접 접근 차단
```

| 서비스 | 월 비용 (소규모) |
|--------|----------------|
| S3 | ~$1 |
| CloudFront | ~$1 (프리 티어 1TB/월) |
| Route53 | ~$1 |
| **합계** | **~$3/월** |

## 패턴 2: API 서버 + DB (난이도: 중)

Node.js/Python API 서버와 데이터베이스.

```
[사용자] → [ALB] → [EC2 / ECS Fargate] → [RDS (프라이빗)]
                        └── [S3 (파일 업로드)]
```

**서버리스 변형:**
```
[사용자] → [API Gateway] → [Lambda] → [DynamoDB]
                              └── [S3 (파일 업로드)]
```

| 구성 | 월 비용 (소규모) | 관리 부담 |
|------|----------------|----------|
| EC2 + RDS | ~$50 | 중간 |
| Fargate + RDS | ~$60 | 낮음 |
| Lambda + DynamoDB | ~$5 (프리 티어 내) | 매우 낮음 |

## 패턴 3: 풀스택 웹앱 (난이도: 중상)

프론트엔드 + 백엔드 + DB + 파일 저장.

```
[사용자]
    ├── [CloudFront] → [S3 (프론트엔드)]
    └── [ALB] → [ECS Fargate (백엔드)]
                    ├── [RDS PostgreSQL (프라이빗)]
                    ├── [ElastiCache Redis (세션/캐시)]
                    └── [S3 (업로드 파일)]
```

| 서비스 | 월 비용 |
|--------|--------|
| CloudFront + S3 | ~$3 |
| ALB | ~$18 |
| Fargate (0.5 vCPU, 1GB) | ~$18 |
| RDS db.t3.small | ~$36 |
| ElastiCache t3.micro | ~$14 |
| **합계** | **~$90/월** |

## 패턴 4: 이벤트 기반 처리 (난이도: 중)

파일 업로드 → 자동 처리 (썸네일 생성, 데이터 변환 등).

```
[S3 업로드 이벤트] → [Lambda (처리)] → [S3 (결과 저장)]
                                        └── [DynamoDB (메타데이터)]
```

## 공통 보안 체크리스트

모든 패턴에 적용:

- [ ] VPC 사용 (기본 VPC 아닌 커스텀 VPC)
- [ ] DB는 프라이빗 서브넷에 배치
- [ ] Security Group은 최소 포트만 개방
- [ ] SSH 대신 Session Manager 사용
- [ ] 모든 저장소 암호화 활성화 (S3, RDS, EBS)
- [ ] IAM 역할 사용 (Access Key 하드코딩 금지)
- [ ] CloudTrail 활성화 (누가 무엇을 했는지 감사 로그)
- [ ] AWS Budgets 설정 (비용 알림)

## 리전 선택

| 사용자 위치 | 권장 리전 | 코드 |
|-----------|----------|------|
| 한국 | 서울 | ap-northeast-2 |
| 일본 | 도쿄 | ap-northeast-1 |
| 미국 동부 | 버지니아 | us-east-1 |
| 미국 서부 | 오레곤 | us-west-2 |
| 유럽 | 프랑크푸르트 | eu-central-1 |

서울 리전이 기본. 글로벌 서비스 시 us-east-1 (가장 저렴하고 서비스 가장 먼저 출시).
